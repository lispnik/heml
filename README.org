


* Xoamax REAME

** About Xoamax

   Xoamax is an Emacs-style editor written in Common Lisp.

   Originally named Hemlock and written as a part of CMUCL, work
   started in 2002 to make it portable to other Common Lisp
   implementations, and in 2020 the Xoamax (amicalble) fork was created.


** Backends

   This version of Hemlock has two backends, of which you need at least
   one:

     * The TTY backend doesn't need much, except for a terminal
       and an installed terminfo database.  SBCL or ECL.

     * The Cocoa backend is a native macOS window, drawn with AppKit
       through [[https://github.com/lispnik/objc][objc]].  SBCL on macOS only.


** macOS

   Dependencies come from [[https://github.com/ocicl/ocicl][ocicl]], including objc and
   [[https://github.com/lispnik/asdf-macos-app][asdf-macos-app]], and iolib needs =libfixposix= (=brew install
   libfixposix=).  =conium= is a git submodule in =vendor/conium=, so
   clone with =--recursive= or run =make deps=.

   #+BEGIN_SRC shell  :tangle no
     make deps       # git submodule update --init; ocicl install
     make run        # the editor in a window, from a terminal SBCL
     make smoke      # drive it end to end and check it; pictures in build/smoke
     make smoke-tty  # the same for the TTY backend, in tmux
     make smoke-tty-ecl  # the TTY checks under ECL
     make demo       # a video of the TTY editor in build/demo (needs vhs)
     make demo-full  # that, the Cocoa editor's, and both with titles (needs ffmpeg)
     make run-tty    # the terminal editor, in this terminal (LISP=ecl for ECL)
     make app        # build/Xoamax.app, signed ad hoc or with SIGN_IDENTITY
     make install-cli  # link the app's xoamax command into ~/.local/bin
     make smoke-cli  # check that command from a shell
     make check-app  # its signature, Info.plist, and what it links
     make dmg        # dist/Xoamax-<version>-<arch>.dmg
     make release SIGN_IDENTITY=...  # notarise and staple the app and the dmg
   #+END_SRC

   From a REPL:

   #+BEGIN_SRC lisp  :tangle no
     (asdf:load-system :hemlock.cocoa)
     (hemlock:hemlock nil :backend-type :cocoa)
   #+END_SRC

   AppKit needs the process's main thread, so call this from the main
   thread -- a terminal SBCL's REPL -- not from a SLIME or Sly REPL
   thread.  Cocoa is chosen whenever it is loaded, so =:backend-type=
   can usually be left out.

   The left Option key is Meta (=hemlock.cocoa:*option-is-meta*=), and
   the right one types what the keyboard layout puts on it, dead keys
   included (=hemlock.cocoa:*right-option-is-meta*= makes it Meta too).
   Input methods work, their text composed at the cursor.  Wide
   characters -- CJK, fullwidth forms, emoji -- take two columns.

   The kill ring and the clipboard are one: what is killed or copied
   (C-w, M-w, Cmd-X, Cmd-C) can be pasted in other applications, and
   what they copy is what the next yank (C-y, Cmd-V) inserts.  The Edit
   menu's Undo, Cut, Copy, Paste and Select All are Command keys bound to
   Hemlock commands, so they can be rebound like any other key.

   Xoamax.app opens files from Finder -- Open With, a drop on its Dock
   icon, =open -a Xoamax file= -- in the running editor.

   The app is also a command.  =make install-cli= links
   =Xoamax.app/Contents/Resources/bin/xoamax= into =~/.local/bin=, and
   then =xoamax file= opens the file in a window, =xoamax --tty file= edits
   it in the terminal, and =xoamax --help= lists the options.

   View > Show Fonts (Cmd-T) picks the font, and Cmd-+, Cmd-- and Cmd-0
   make it bigger, smaller, or the default size again; the commands
   "Select Font", "Increase Font Size", "Decrease Font Size" and "Default
   Font Size" do the same.  The choice is kept for the next session.
   Cmd-Q and the close button do what C-x C-c does.

   The mouse works as elsewhere on the Mac: click to move point (or, on a
   modeline, to select that window), drag to mark a region, shift-click
   to extend it, double-click for a word, triple-click for a line, and
   scroll with the wheel or trackpad.  The region shows in the system's
   selection colour.  A right click opens a menu -- Cut, Copy, Paste,
   Edit Definition, Describe Symbol, Evaluate Region -- acting on the
   selection, or on where it was clicked.

   The menu bar has the File, Edit, View, Buffer, Lisp, Window and Help
   menus a Mac user looks for: Open and Save As use the standard panels,
   Settings opens the init file, and every other item is a Hemlock
   command (=*menu-bar*= in =src/cocoa-appkit.lisp=).

   Shells show their colours, and the escape sequences that are not
   colours are left out of the buffer.

   Xoamax.app is built by [[https://github.com/lispnik/asdf-macos-app][asdf-macos-app]], and signed ad hoc unless
   =SIGN_IDENTITY= names a Developer ID.  =RELEASING.md= says how to
   notarise it and make a release.

   CI (=.github/workflows/ci.yml=) runs the smoke tests, builds the app
   and its disk image on every push, and keeps the smoke test's pictures.
   A tag =v*= runs =.github/workflows/release.yml=, which builds, signs,
   notarises and staples a disk image for Apple silicon and one for Intel,
   and publishes them as a release.

    #+BEGIN_SRC shell  :tangle no
      ./build.sh

    #+END_SRC


** Building and invocation from the REPL
   #+BEGIN_SRC lisp  :tangle no
     (push #p"/path/to/hemlock/" asdf:*central-registry*)
     (asdf:operate 'asdf:load-op :hemlock.tty)

     (hemlock:hemlock)
   #+END_SRC

 or just

   #+BEGIN_SRC lisp  :tangle no
     (ed)
   #+END_SRC
   

** Misc issues
   Note, libfixposix is currently required for running Xomax (through
   iolib).  upon installation of libfixpostfix, you need to eather
   reboot your machine, so that the library can be found or execute
   the following lisp:

   #+BEGIN_SRC lisp  :tangle no
     (push "/usr/local/lib/" cffi:*foreign-library-directories*)
   #+END_SRC
